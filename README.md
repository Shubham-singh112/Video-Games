
#  Video Games Sales Analysis

##  About the Project
This project focuses on analyzing video game sales data using Python. It explores sales trends, popular genres, gaming platforms, regional performance, and the relationship between critic scores and sales.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

##  Project Visualizations

The project includes the following visualizations:

1. Genre Counts
2. Regional Sales Analysis
3. Average Sales by Genre
4. Games Released by Year
5. Games Released by Decade
6. Critic Scores vs Sales
7. Sales by Score Category
8. Average Sales by Platform
9. Sales Distribution
10. Regional Sales Correlation
